# Loaf Skill Authoring

Use this reference for authoring work in the Loaf repository. The [Skill Architecture guide](../../../docs/knowledge/skill-architecture.md) owns the detailed rules.

## Critical Rules

- Before creating or editing an affected file, read the canonical guide and apply its relevant sections, including when the task only changes existing prose.
- Keep detailed conventions in the guide. This skill supplies task-time routing; it is contributor tooling and stays outside Loaf's distributable content.

## Verification

Apply the guide's [Authoring Checklist](../../../docs/knowledge/skill-architecture.md#authoring-checklist) and the repository's [Before Committing checks](../../../AGENTS.md#before-committing) to the change.
